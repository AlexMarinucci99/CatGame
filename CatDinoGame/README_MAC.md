# 🐱 MasterCat - Avventura Spaziale

## 🍎 **ISTRUZIONI PER MAC**

### 🎮 **GIOCA SUBITO!**

1. **Apri il Terminale**
2. **Vai nella cartella del gioco:**
   ```bash
   cd /percorso/alla/cartella/CatDinoGame
   ```
3. **Esegui il launcher:**
   ```bash
   chmod +x GIOCA_MAC.sh
   ./GIOCA_MAC.sh
   ```

### 📋 **Prerequisiti (installazione automatica se mancanti)**

- **Java 11+** → Il launcher ti dirà come installarlo se manca
- **JavaFX** → Incluso nella cartella `MasterCat/lib/`

### 🎯 **Controlli di Gioco**

| Tasto | Azione |
|-------|--------|
| **SPAZIO** | Salto singolo |
| **SPAZIO x2** | Doppio salto |
| **C** | Onda Energetica |
| **X** | Scudo (Boss Fight) |
| **← → (A/D)** | Movimento (Boss Fight) |
| **ESC / U** | Fullscreen ON/OFF |
| **M** | Toggle Audio |
| **I** | Impostazioni |

### 🔧 **Opzioni Avanzate**

Se vuoi più controllo, vai nella cartella MasterCat:
```bash
cd MasterCat
chmod +x *.sh
./run_game_mac.sh    # Launcher completo con menu
```

### 🆘 **Problemi?**

Il launcher `GIOCA_MAC.sh` diagnostica automaticamente i problemi e mostra come risolverli!
