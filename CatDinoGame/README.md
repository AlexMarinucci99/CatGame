# 🐱 MasterCat - Avventura Spaziale

Un emozionante gioco platformer spaziale dove controlli un gatto coraggioso!

## 🎮 **GIOCA SUBITO**

### 🪟 **Windows:**
```cmd
RUNMASTERCAT.bat
```

### 🍎 **Mac:**
```bash
chmod +x GIOCA_MAC.sh
./GIOCA_MAC.sh
```

## 🎯 **Controlli**

| Tasto | Azione |
|-------|--------|
| **SPAZIO** | Salto singolo |
| **SPAZIO x2** | Doppio salto |
| **C** | Onda Energetica |
| **X** | Scudo (Boss Fight) |
| **← → (A/D)** | Movimento (Boss Fight) |
| **ESC / U** | Fullscreen ON/OFF |
| **M** | Toggle Audio |
| **I** | Impostazioni |

## 📁 **Struttura Progetto**

```
CatDinoGame/
├── RUNMASTERCAT.bat     # 🪟 Launcher Windows
├── GIOCA_MAC.sh         # 🍎 Launcher Mac
├── README_MAC.md        # 📖 Guida dettagliata Mac
└── MasterCat/           # 📂 Codice sorgente
    ├── src/             # Java + risorse
    ├── lib/             # JavaFX
    └── *.bat            # Script Windows
    └── *.sh             # Script Mac
```

## 🚀 **Caratteristiche**

- 🎮 Gameplay platformer classico
- 🌊 Sistema di onde energetiche
- 🛡️ Meccaniche di scudo
- 👹 Boss fight epico
- 🎵 Colonna sonora coinvolgente
- 🖥️ Supporto fullscreen
- 💾 Punteggio progressivo

## 📋 **Requisiti**

- **Java 11+** (consigliato Java 21)
- **JavaFX** (incluso)

## 🔧 **Sviluppo**

Per modifiche al codice, vai nella cartella `MasterCat/` e usa gli script di sviluppo appropriati per il tuo sistema operativo.
