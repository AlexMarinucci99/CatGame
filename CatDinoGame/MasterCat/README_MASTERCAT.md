```bash
# Naviga nella cartella principale
cd c:\Users\marin\Desktop\CatDinoGame

# Esegui il nuovo script

```

### 🎮 **Controlli di Gioco**
- **SPAZIO**: Salto singolo
- **SPAZIO x2**: Doppio salto  
- **C**: Lancia Sfera Dragon Ball
- **X**: Scudo (Boss Fight) - **Durata: 5 secondi**
- **← → (A/D)**: Movimento (Boss Fight)
- **M**: Toggle Audio
- **U**: Toggle Fullscreen

### 🌟 **Caratteristiche**
- **Scudo potenziato**: Dura 5 secondi invece di 2
- **Sistema di combattimento unificato**: Sfere Dragon Ball in tutto il gioco
- **Boss Fight epico**: Combatti il Corriere Amazon con le nuove meccaniche!
