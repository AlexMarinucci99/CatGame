## Sfondo Game Over Personalizzato

Per usare un'immagine personalizzata come sfondo della schermata Game Over:

1. Salva la tua immagine come:
   - `gameover_background.png` (formato PNG consigliato)
   - oppure `gameover_background.jpg` (formato JPG alternativo)

2. Metti il file in questa cartella: `src/main/resources/images/backgrounds/`

3. Il gioco caricherà automaticamente l'immagine come sfondo della schermata Game Over

Se nessuna immagine viene trovata, il gioco userà lo sfondo nero di default.

NOTA: L'immagine verrà automaticamente scalata per coprire tutto lo schermo mantenendo le proporzioni.
